# Generated World Data

The six JSON collections in this directory and `containers/` are generated by:

```text
python tools/build_world.py
```

Edit the authoritative arrays under `data/source/world/`, not these generated JSON files.
See `data/source/world/README.md` for source organisation, validation, and packaging.

Before committing or running against changed data, check:

```text
python tools/build_world.py --check
```

The Lua world loader reads these category files and derives runtime indexes as before.
Generated files remain tracked alongside their sources so the checked-out tracker can run
without requiring a Python build at runtime.
